# AI_Finance_Sec 작업 에이전트 운영 구성

## 확인 경로

이 문서는 프로젝트 작업 에이전트의 역할과 최근 확인 상태를 사용자가 직접 확인하기 위한 운영 대장이다.

- 메인: `/root`
- 개발·형상관리: `/root/development_git`
- 비판·리스크 리뷰: `/root/architecture_review`
- 검증·QA: `/root/verification_qa`

## 현재 상태

| 에이전트 | 역할 | 최근 상태 |
|---|---|---|
| `/root` | 사용자 협의, 설계, 분배, 통합, 최종 보고 | 운영 중 |
| `/root/development_git` | 승인된 구현, 테스트, 로컬 Git commit | Qwen P1 개발 완료·commit `50884b6` |
| `/root/architecture_review` | 읽기 전용 비판·리스크 검토 | P0/P1 최종 승인·차단 없음 |
| `/root/verification_qa` | 독립 검증·QA·출시 판단 | P0/P1 최종 GO |

## UI 표시 방식

위 에이전트들은 현재 Codex 작업 내부에서 동작하는 서브에이전트이므로 사이드바에 별도 작업으로 표시되지 않는다. 사이드바에는 사용자가 직접 열고 대화하는 독립 Codex 작업만 표시된다.

서브에이전트의 실시간 상태는 메인이 내부 에이전트 목록을 조회해 이 문서 또는 채팅으로 보고한다. 이 파일은 자동 갱신되는 모니터가 아니며, 중요한 작업 배정·완료 시 메인이 갱신한다.

## 운영 원칙

- 사용자는 메인 작업에서 지시한다.
- 메인이 각 서브에이전트에 구체적인 범위와 완료 기준을 전달한다.
- 서브에이전트 결과는 메인에게 반환된다.
- 메인이 충돌과 품질을 조정해 사용자에게 통합 결과를 보고한다.
- 사이드바에서 각 역할과 직접 대화해야 한다면 서브에이전트가 아니라 별도의 사용자 소유 Codex 작업 세 개를 생성해야 한다.
